## 0. 피벗 선언 (가장 중요)

### ❗ v1 → v2 근본 피벗
```
v1 (기존):                          v2 (새로운):
배린이 플랫폼 + PLF 수익화    →    동호회 운영 SaaS (버디모아 중심)
타깃: 배드민턴 입문자               타깃: 동호회 총무·총장
수익: PDF 판매 (PLF)               수익: 우선 무결제, 성장 우선
KPI: 이메일 구독자 수               KPI: 실 사용 클럽 수
콘텐츠: 메인                        콘텐츠: 경량 유입 훅
버디모아: 서브                      버디모아: 메인 (전체 제품)
```

**이유:** 기존 기획(배린이 콘텐츠 + PLF)과 실제 개발된 버디모아(클럽 SaaS)가 내부적으로 충돌 → "두 제품이 한 사이트에 섞임"이 꼬임의 근본 원인.

### 도메인 범위
- **v2.0**: 배드민턴 동호회 전용 (하드코딩 선언)
- **v2.1+**: 범용화(스터디·독서모임 등)는 요구 생기면 그때

|---|---|
| 이름 | Birdieminton (유지) / 버디모아 (내부 앱명) |

   /                  버디모아 랜딩 (총무 대상)

   /quiz              17문항 레벨 진단
   /quiz/result       결과 (개선) + "내 클럽 찾기" CTA
   /login             카카오 소셜
   /club/new          신규 클럽 생성
   /club/join         초대코드 입력
   /club/[id]         클럽 대시보드
   /club/[id]/members 회원 관리
   /club/[id]/games   게임보드
   /club/[id]/dues    정산 (프라이버시 모드)
   /club/[id]/ranking 랭킹
   /club/[id]/notices 공지
   /club/[id]/settings 설정 (총무만)

### 12-1. 전체 구조 (5 섹션)

```
/me
├─ A. 프로필 카드 (상단)
│   ├ 카카오 프로필 이미지 (또는 사용자 업로드)
│   ├ 닉네임 (서비스 전체용)
│   ├ 내 레벨 (퀴즈 또는 수동)
│   ├ 스킬점수 평균 (클럽별 계산값의 평균)
│   ├ 가입일
│   └ [프로필 편집]
│
├─ B. 내 클럽 & 활동
│   ├ 소속 클럽 카드 리스트 (복수 가입 허용)
│   │   ├ 클럽명 + 역할 뱃지(owner/member)
│   │   ├ 이번 달 출석·승률·랭킹
│   │   └ 클럽 바로가기 CTA
│   └ 하단 액션: [새 클럽 만들기] [초대코드로 가입]
│
├─ C. 내 정산 요약 (이번 달)
│   ├ 클럽별 납부 현황 (본인 금액만)
│   ├ 총 미납 금액
│   └ 납부 액션 (카카오페이 딥링크)
│
├─ D. 배드민턴 프로필
│   ├ 내 레벨 · [퀴즈 다시하기]
│   ├ 주 라켓 · [도감에서 선택]
│   └ 플레이 타입 (공격/수비/올라운드)
│
└─ E. 계정 관리
    ├ 알림 설정 (이메일 on/off)
    ├ 연결 계정 (카카오 연결 상태)
    ├ 로그아웃
    └ 탈퇴 (2단계 확인 + 데이터 처리 안내)
```

### 12-2. 편집 가능 / 불가 항목

| 항목 | 편집 | 특이사항 |
|---|---|---|
| 프로필 이미지 | ✅ | 카카오 기본값 사용 or 업로드 오버라이드 |
| 닉네임 (서비스 전체) | ✅ | 필수, 고유성 체크 X (중복 허용) |
| **닉네임 (클럽별)** | ✅ | 각 클럽에서 별칭 설정 가능 (예: A클럽 "영희", B클럽 "코치님") |
| 내 레벨 | ✅ | 퀴즈 재진단 or 수동 선택 |
| 주 라켓 | ✅ | 도감에서 선택 |
| 플레이 타입 | ✅ | 공격/수비/올라운드 |
| 알림 설정 | ✅ | 이메일·카톡 공유 on/off |
| 스킬점수 | ❌ | 클럽 내 활동 기반 자동 산정 |
| 승률·경기수·랭킹 | ❌ | 시스템 집계 |
| 가입일 | ❌ | 시스템 기록 |
| 역할(role) | ❌ | owner는 클럽 설정에서 이양, member는 자동 |

## 13. 클럽 생성·가입 플로우 & 권한 정책

### 13-1. 진입 플로우

```
[홈(/)] "무료로 시작하기"
    ↓
[/login] 카카오 소셜 로그인 (최초 유저 자동 생성)
    ↓
[/onboard] 두 갈림길
    ├─ [클럽 만들기]    → /club/new
    └─ [초대코드 입력]  → /club/join

4-A. /club/new (신규 클럽 생성)
    ├ 클럽명 (필수)
    ├ 지역 (선택, 추후 매칭용)
    ├ 대표 이미지 (선택)
    ├ 월회비 기본값 (0원 가능)
    ├ 정기모임 요일·시간 (선택, 공지 템플릿용)
    └ 생성 완료 → 초대코드 자동 생성 → 단톡방 공유 안내

4-B. /club/join (초대코드 입력)
    ├ 코드 검증 → 성공 시 자동 가입 (승인 큐 없음)
    └ /club/[id] 대시보드 랜딩
```

### 13-2. 권한 모델 (v2.0)

| 역할 | 권한 |
|---|---|
| **owner** (총무·클럽장) | 클럽 설정·회비 규칙·항목 생성·멤버 강퇴·공지 작성·정산 확정·클럽 삭제 |
| **member** (일반) | 내 정산 조회·출석 체크·공지 읽기·랭킹 조회 |

**v2.1+**: `manager` 역할 추가 (owner가 위임, 클럽 삭제·권한 변경 제외한 운영 작업 가능)

### 13-3. 클럽 생성 조건
- 카카오 로그인만 있으면 누구나 가능 (추가 인증·심사 없음)
- **한 유저가 동시 보유 가능한 owner 클럽 최대 3개** (하드 캡)
- 3개 제한 도달 시 UX: "먼저 기존 클럽을 정리해주세요" + 기존 owner 클럽 리스트 안내
- 클럽 삭제 시 슬롯 즉시 반환 (예: 3개 보유 → 1개 삭제 → 2개 보유 상태에서 신규 생성 가능)
- 비고: member 참가는 이 제한과 무관 (여러 클럽 멤버로 참가 가능)
- 향후 v2.1+ Team 티어에서 제한 해제 옵션 검토

### 13-4. 복수 클럽 멤버십
- **member 참가**: 제한 없음 (여러 클럽 동시 가입 허용)
- **owner 소유**: 최대 3개 (섹션 13-3)
- 각 클럽마다 role 독립 (A클럽 owner, B클럽 member 가능)
- DB: `club_members` 테이블 (user_id, club_id) 복합키
- 추가 제약: `users.owned_clubs_count <= 3` 체크 (Supabase RLS 또는 application guard)
- 마이페이지에서 "소속 클럽 리스트" 형태로 표시 (owner 뱃지 강조)

### 13-5. 모임(일회성) vs 클럽(정기) 구분

| 타입 | 특성 | v2.0 범위 |
|---|---|---|
| **클럽** | 영속적 조직 + 월회비 + 멤버 목록 + 랭킹 | ✅ MVP |
| **일회성 모임(정산 B트랙 내 C항목)** | 회식·이벤트 · 참가자 선택 분배 · 영속 X | ✅ MVP (클럽 내부만) |
| **공개 URL 정산** | 비클럽·외부인 포함 | ❌ v2.1 |

일회성 정산의 "모임장"은 그 정산을 만든 사용자 (= 그 이벤트의 주최자 역할). 별도 테이블 없이 `dues_items.created_by`로 표현.
